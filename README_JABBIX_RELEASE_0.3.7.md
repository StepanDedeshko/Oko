# Jabbix / тема «Жабка» — финальные ассеты для релиза 0.3.7

Архив подготовлен для release-ветки, которая объединяет:

- PR #98 — тема «Жабка»;
- PR #99 — критические ЕЦХД/ТИБ-триггеры.

## Как использовать

Распаковать содержимое папки `jabbix_release_assets_0.3.7` в корень репозитория,
сохраняя структуру каталогов.

Финальные файлы:

- `assets/themes/jabka/backgrounds/00_main_menu_wallpaper.png`
  — готовый фон главного меню с жабой и нарисованной панелью.
- `assets/themes/jabka/backgrounds/10_settings_menu_wallpaper.png`
  — готовый фон меню настроек.
- `assets/themes/jabka/sounds/frog_croak.wav`
  — квак при нажатии на жабу в главном меню.
- `app/assets/sounds/jabbix_graph_check_kvak.wav`
  — выбранный квак уведомления о проверке графиков.
- `app/assets/sounds/jabbix_update_found_kvak.wav`
  — выбранный квак уведомления о найденном обновлении.

## Важно

- Не использовать старые фоновые изображения, промежуточные арты и MP4.
- Не добавлять отдельную рамку поверх главного фона: рамка уже встроена в PNG.
- Уведомительные звуки включать только для темы `jabka` / Jabbix.
- При выключенных пользователем звуках ничего не воспроизводить.
- Не изменять и не перезаписывать `config.json`, `credentials.json`,
  WebEngine-профили, cookies и другие пользовательские данные.
- Номер версии менять только в общей release-ветке.
