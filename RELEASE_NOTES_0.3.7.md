# Око 0.3.7

## Главное

- Добавлена полноценная тема **«Жабка» / Jabbix** с фонами, иконкой, заставкой, звуками и отдельной стилизацией рабочих страниц.
- Переработан Live Zabbix Monitor: кнопка обновления, более читаемая таблица проблем, контрастные выделения и оптимизированная отрисовка без тяжёлой перерисовки всей таблицы.
- Добавлен отдельный flow для пяти критических ЕЦХД/ТИБ-триггеров.
- Все общие рабочие URL сведены в единый раздел **«Настройки → Ссылки»**.
- Переработаны страницы **«Проверка сервисов»** и **«Профиль»**.
- Добавлены безопасная новая установка и обновление существующей копии без потери пользовательских данных.

## Критические триггеры

Для пяти критических сценариев доступно только создание задачи Redmine. Действия ММ, «Наблюдаю», «Не требует обработки» и копирование комментария блокируются также на уровне обработчиков.

Flow выполняет:

1. распознавание критической строки;
2. загрузку history.php через скрытый WebView с постоянным профилем Live Zabbix;
3. анализ метрики `*_share_slow`;
4. при `share_slow < 50%` дополнительную проверку операций за последние 30 минут;
5. получение PNG-графиков из авторизованной Zabbix-сессии;
6. прикрепление графиков к Redmine и вставку изображений в описание задачи;
7. получение реального номера задачи Redmine;
8. добавление комментария в Zabbix;
9. обязательное подтверждение критической проблемы.

Для сценария «время с последнего запроса >120 минут» прикрепляется основной график. Для остальных сценариев дополнительный график прикрепляется только когда этого требует результат анализа.

Технические инструкции и внутренний отчёт Око больше не попадают в описание Redmine. Если обязательное изображение не удалось получить или загрузить, создание задачи блокируется, чтобы задача не ушла без графика.

Обычные и специальные некритические триггеры сохраняют прежний flow.

## Тема «Жабка»

В релиз включены все финальные бинарные ассеты:

```text
assets/themes/jabka/backgrounds/00_main_menu_wallpaper.png
assets/themes/jabka/backgrounds/10_settings_menu_wallpaper.png
assets/themes/jabka/sounds/frog_croak.wav
app/assets/sounds/jabbix_graph_check_kvak.wav
app/assets/sounds/jabbix_update_found_kvak.wav
```

Звуковая логика:

- `frog_croak.wav` используется кликабельной жабкой на главной странице;
- `jabbix_graph_check_kvak.wav` используется уведомлением проверки графиков;
- пользовательский файл `duty_mode.sound_path` имеет приоритет;
- `jabbix_update_found_kvak.wav` воспроизводится при обнаружении новой версии;
- звуки темы не влияют на остальные темы;
- `sound_enabled=false` полностью отключает уведомления.

Исправлены контраст текста при выделении и светлые системные подсказки. Таблица Live Zabbix получила карточное оформление строк, hover и заметное выделение, а затем была оптимизирована для работы с сотнями проблем.

## Единые рабочие ссылки

Единственное место редактирования общих URL — **«Настройки → Ссылки»**:

- URL создания задачи Redmine;
- URL окна авторизации Redmine;
- URL создания обычной задачи ОТРС;
- URL создания задачи ОТРС ММ;
- URL Live Zabbix Monitor.

Дубли URL убраны из режима разработчика, настроек дежурки, шаблонов Redmine и Профиля. При первом запуске значения безопасно восстанавливаются из старых мест хранения. Старые ключи остаются внутренними зеркалами совместимости, но больше не могут перезаписать новое значение.

## Проверка сервисов

Страница разделена на две постоянные колонки:

- слева — группы общих доступов, список созданных групп, название и сервисы группы;
- справа — продукты и полная карточка выбранного продукта.

Сервисы можно включать в группу чекбоксом или двойным кликом. Отметка остаётся видимой даже на выделенной строке. Исправлен сброс курсора при переименовании группы.

## Профиль

Страница разделена на:

- **Интеграции**: OTRS, Zabbix и Redmine;
- **Группы сервисов**: выбор группы и её личные логин/пароль.

Кнопка выхода из аккаунта Око перенесена вниз страницы и выделена как опасное действие. Существующие ключи credentials и логика сохранения не менялись.

## Установка и обновление

### Новая установка

1. Скачайте `Oko-0.3.7-linux.zip`.
2. Распакуйте архив.
3. Откройте терминал в папке `Oko-0.3.7`.
4. Выполните:

```bash
bash install.sh
```

Установщик проверяет Ubuntu 22.04/24.04 LTS, системные библиотеки, Python, `.venv`, PySide6 и QtWebEngine, создаёт ярлык и запускает Око.

### Обновление существующей версии

В Око откройте раздел обновления и запустите обновление приложения. Око получает файл `update.zip` из последнего GitHub Release.

Для ручного обновления:

```bash
bash UPDATE_OKO.sh --archive /путь/к/update.zip
```

Перед обновлением создаётся резервная копия. Не удаляются и не перезаписываются:

```text
config.json
credentials.json
web_profiles/
data/
user_data/
logs/
```

## Релизные файлы

- `update.zip` — компактное обновление для установленной Око;
- `Oko-0.3.7-linux.zip` — полный архив для новой установки;
- `SHA256SUMS.txt` — контрольные суммы архивов.

В архивы не включаются тесты, CI, кэши, логи, `credentials.json` и другие пользовательские данные. Все runtime-ассеты темы включены.
