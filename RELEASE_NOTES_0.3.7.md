# Око 0.3.7 — черновик релиза

## Главное

- Добавлена тема **«Жабка» / Jabbix** с отдельным оформлением главного меню, настроек, заставки, кнопок и звуков.
- Добавлен отдельный безопасный flow для пяти критических ЕЦХД/ТИБ-триггеров Live Zabbix.
- Все общие рабочие URL сведены в единый раздел **«Настройки → Ссылки»**.
- Добавлен единый установщик `install.sh` для новой установки и обновления существующей копии.
- Усилена защита пользовательских данных в `UPDATE_OKO.sh`.

## Критические триггеры

Для пяти критических сценариев доступно только создание задачи Redmine. Обычные действия обработки заблокированы как в интерфейсе, так и в обработчиках.

Flow выполняет:

1. распознавание критической строки;
2. загрузку history.php через скрытый WebView с постоянным профилем Live Zabbix;
3. анализ метрики `*_share_slow`;
4. при необходимости проверку операций за последние 30 минут;
5. формирование отдельного описания Redmine со ссылками на графики;
6. получение реального номера задачи Redmine;
7. добавление комментария в Zabbix;
8. обязательное подтверждение критической проблемы.

Временные PNG не создаются. Обычные и специальные некритические триггеры продолжают использовать прежний flow.

## Тема «Жабка»

Добавлены runtime-модули `app/jabka_*.py`, SVG-ассеты темы и подключение темы из `main.py` без вмешательства в бизнес-логику Zabbix, Redmine, OTRS и проверок сервисов.

Финальный набор бинарных ассетов:

```text
assets/themes/jabka/backgrounds/00_main_menu_wallpaper.png
assets/themes/jabka/backgrounds/10_settings_menu_wallpaper.png
assets/themes/jabka/sounds/frog_croak.wav
app/assets/sounds/jabbix_graph_check_kvak.wav
app/assets/sounds/jabbix_update_found_kvak.wav
```

Звуковая логика:

- `frog_croak.wav` используется кликабельной жабкой на главной странице;
- `jabbix_graph_check_kvak.wav` используется уведомлением проверки графиков;
- пользовательский файл `duty_mode.sound_path` имеет приоритет для проверки графиков;
- `jabbix_update_found_kvak.wav` воспроизводится при обнаружении новой версии;
- звуки работают только при активной теме `jabka`;
- настройка `sound_enabled=false` полностью отключает звуки уведомлений;
- кнопка «Убрать звук» снимает этот флаг, а выбор пользовательского файла включает его снова;
- другие темы продолжают использовать прежнюю звуковую логику.

## Единые рабочие ссылки

Единственное место редактирования общих URL — **«Настройки → Ссылки»**.

Там находятся:

- URL создания задачи Redmine;
- URL окна авторизации Redmine;
- URL создания обычной задачи ОТРС;
- URL создания задачи ОТРС ММ;
- URL страницы Zabbix Problems.

Дубли URL убраны из:

- режима разработчика;
- «Настройки дежурки → Основное»;
- «Настройки дежурки → ОТРС»;
- редактора шаблонов Redmine.

При первом запуске 0.3.7 значения безопасно восстанавливаются из старых мест хранения, включая `duty_mode`, `live_zabbix_monitor`, шаблоны Redmine и старую страницу `problems_page`. После миграции `duty_links` становится единственным источником данных. Старые ключи остаются внутренними зеркалами совместимости, поэтому существующие модули продолжают работать, но больше не могут перезаписать новое значение со старой страницы. Явно очищенная ссылка не восстанавливается повторно из устаревшей копии.

## Установка

Основной сценарий для новой Ubuntu:

```bash
bash install.sh
```

Установщик:

- проверяет Ubuntu, Python, права на каталог и возможность записи настроек;
- определяет недостающие apt-пакеты и предлагает установить их через `sudo`;
- использует нативный `/usr/bin/curl`, а не Snap curl;
- различает новую установку и обновление существующей копии;
- создаёт `.venv` и устанавливает `requirements.txt`;
- проверяет импорт PySide6 и QtWebEngine;
- компилирует `main.py` и Python-модули;
- создаёт ярлык и запускает Око.

Старые точки входа `INSTALL_OKO.sh`, `INSTALL_OKO_GUI.sh` и `install_gui.sh` перенаправлены на тот же безопасный сценарий.

## Проверка перед публикацией

```bash
bash CHECK_RELEASE.sh
python3 main.py
```

На текущем составе release-ветки выполнено:

```text
382 passed, 1 warning
```

GitHub Actions дополнительно создаёт страницы «Ссылки», режима разработчика, настроек дежурки и шаблонов в offscreen-режиме и проверяет:

- все пять общих URL редактируются на странице «Ссылки»;
- поля URL скрыты в остальных разделах;
- открытая старая страница дежурки не может вернуть устаревшее значение;
- миграция сохраняет прежний формат `duty_links` без служебных полей;
- явная очистка ссылки не отменяется старым legacy-значением.

Shell-синтаксис, `git diff --check` и asset-gate прошли. Предупреждение относится к старой escape-последовательности в `tests/test_live_zabbix_monitor.py` и не связано с релизными изменениями.

Ручная проверка должна включать Live Zabbix, Redmine, OTRS, проверки сервисов, обычные и специальные триггеры, критический flow, тему «Жабка», остальные темы, три звуковых сценария, единую страницу ссылок и повторный запуск приложения.
